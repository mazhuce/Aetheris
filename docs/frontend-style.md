# 前端设计规范

本规范用于保证 Aetheris 前端长期风格一致，后续所有页面与组件必须遵守。

## 技术栈

- React 18 + TypeScript
- Vite
- Ant Design 5（企业级组件库）
- @ant-design/icons（图标）

## 设计语言：克制的企业级控制台

### 整体原则

1. 浅色中性底，白卡片，细边框；禁止渐变、玻璃拟态、大块发光。
2. 单一主色 `#2563eb`（蓝），仅用于主操作、选中态、链接。
3. 信息密度优先：表格、指标卡、状态标签是主要元素。
4. 文案客观、简洁，禁止口号式、抒情式文案。

### 颜色

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f5f7fa` |
| 卡片/容器背景 | `#ffffff` |
| 主色 | `#2563eb` |
| 主文字 | `#111827` |
| 次要文字 | `#6b7280` |
| 边框 | `#e5e7eb` |
| 成功/警告/错误 | `#16a34a` / `#d97706` / `#dc2626` |

### 布局

- 左侧导航（宽 220px，白底，右侧细边框）+ 顶部栏（56px）+ 内容区（24px 内边距）。
- 卡片圆角 8px，间距 16px，标题 16px。

### 组件约定

- 指标卡：图标 + 标签 + 数值/状态 + 底部说明。
- 表格：`size="middle"`，默认不分页（数据量小），空状态要有说明。
- 状态：用 `Tag` 表示，在线/离线/检测中对应 success/error/warning。
