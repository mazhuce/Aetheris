# Aetheris 前端设计规范

本规范定义数据中台的全局界面语言。新增页面应复用现有令牌和公共组件，避免在页面内重新定义视觉规则。

## 技术栈

- React 18 + TypeScript + Vite
- Ant Design 5 与 `@ant-design/icons`
- 样式入口：`apps/web/src/styles/global.css`
- 站点图标唯一入口：`apps/web/public/AETHRIS.png`；页面入口和 `BrandMark` 必须引用带版本参数的 `/AETHRIS.png?v=20260930`，旧 SVG 图标文件仅作兼容保留。变更图标时必须同步更新路径或版本参数，避免浏览器 favicon 缓存继续显示旧图。

## 设计原则

1. 内容优先于导航，导航优先于装饰。
2. 保持高信息密度、低视觉噪声和清晰层级。
3. 使用黑白灰中性色；彩色仅用于成功、警告、错误等明确状态语义。
4. 禁止渐变、发光、玻璃拟态、大面积阴影、拟物装饰和虚构数据。
5. 不改变既有信息架构、权限边界、路由与业务行为。

## 信息架构与布局

- 一级导航位于顶部，高度 `48px`；空间不足时收进“更多”菜单。
- 二级导航位于一级导航下方，高度 `36px`。
- 内容区采用 `20px` 内边距，主要内容不设置人为的窄版最大宽度。
- 页面结构统一为 `PageHeader → PageToolbar → DataSurface / 内容区`。
- 浮层、抽屉与弹窗在小屏上不得超出视口。

## 设计令牌

令牌集中定义于 `styles/tokens.css`，业务组件只引用语义变量。

### 颜色

| 用途 | 令牌 | 默认值 |
| --- | --- | --- |
| 应用背景 | `--bg-app` | `#101114` |
| 一级表面 | `--bg-surface` | `#16171b` |
| 二级表面 | `--bg-subtle` | `#1a1b20` |
| 主文字 | `--text-primary` | `#eeeef1` |
| 次文字 | `--text-secondary` | `#a8abb3` |
| 弱文字 | `--text-tertiary` | `#777b85` |
| 常规边框 | `--border-default` | `rgba(255, 255, 255, 0.10)` |
| 中性强调色 | `--accent` | `#f0f0f2` |

主按钮使用白底深色文字；成功、警告和错误状态分别使用 `--success`、`--warning`、`--danger`，信息提示使用中性灰 `--info`。禁止将状态色用作大面积装饰。

### 字体与间距

- 正文使用 DeepSeek 官网同类字体链：`DM Sans → Noto Sans SC → PingFang SC → 系统无衬线字体`。
- 标题使用 `Host Grotesk → Noto Sans SC → PingFang SC`；字体资源随前端构建产物本地发布，不依赖外部 CDN。
- 页面标题 `18px`，区块标题 `14px`，正文 `13px`，表格 `12px`，辅助信息与眉题 `11px`。
- 间距采用 `4 / 6 / 8 / 12 / 16 / 20 / 24 / 32px` 序列。
- 控件高度为 `28 / 32 / 36px`，常用紧凑控件使用 `28px`。
- 圆角采用 `4 / 6 / 8px`；阴影仅用于菜单、弹窗等浮层。
- 动效使用 `120–180ms`，并尊重 `prefers-reduced-motion`。

## 公共组件

- `PageHeader`：眉题、标题、说明、元信息和页面级操作。
- `PageToolbar`：搜索、筛选、批量操作和结果摘要。
- `DataSurface`：表格或分区内容的统一边框与标题结构。
- `StatusBadge`：在线、离线、运行中、失败等语义状态。
- `RowActions`：行内保留一个主要操作，其余操作收进菜单。
- `EmptyState`、`ErrorState`、`LoadingState`：统一反馈状态。

## 表格与表单

- 表头约 `34px`、数据行约 `38px`，不使用完整网格边框。
- 列标题简短，数字右对齐；更新时间统一为 `YYYY-MM-DD HH:mm`。
- 横向列过多时只允许表格容器滚动，页面主体不得产生横向滚动。
- 删除等破坏性操作必须二次确认，并显示目标对象名称。
- 表单标签、帮助文案和错误信息保持短句；不使用超大输入框或胶囊按钮。

## 响应式规则

- `1280px` 以下减少导航间距并允许表格容器横向滚动。
- `1024px` 左右将放不下的一级导航收进“更多”。
- `820px` 以下将双栏页面改为单栏，聊天历史等辅助区域改为抽屉。
- 小屏仍需保持页面标题、主要操作与焦点顺序可用。

## 禁止项

- 页面内硬编码颜色、间距与阴影。
- 渐变、发光、玻璃效果、多套组件库并存。
- 为填充页面而生成假指标、假图表或假活动记录。
- 无文本替代的纯图标操作，以及无法通过键盘关闭的浮层。
